<Stage tag="MOTIVE" title="왜 만들었나">

교내 대회(LCG)를 진행하면서 참가팀 정보, 대기 시간, 밴픽 단계, 승리 화면
같은 걸 매끄럽게 보여줄 연출용 화면이 필요했다. 진행자가 즉석에서 종이나
말로 안내하는 것보다, 화면 하나로 딱 정리해서 보여주는 게 훨씬 대회다워
보일 것 같았다.

</Stage>

<Stage tag="BUILD" title="어떻게 만들었나">

Node.js + Express 서버 위에 역할이 다른 여러 개의 화면을 각각의 페이지로
구성했다.

- **index** — 아무 기능 없는 안내용 버튼 화면
- **control** — 진행자가 실시간으로 타이머를 조작하는 컨트롤 페이지
- **timer** — 대기 시간과 팀 정보를 보여주는 메인 화면
- **banpick** — 밴픽 단계를 위한 화면
- **stats** — 직전 게임의 팀별 스탯을 보여주는 화면
- **transition / victory** — 전환·승리 연출 화면

진행자는 control 페이지에서 타이머를 조작하고 그 결과가 메인 화면인
timer 페이지에 실시간으로 반영되는 구조다. 로컬 네트워크 밖에서도 쓸 수
있도록 ngrok 연동 방법까지 문서에 정리해뒀다.

</Stage>

<Stage tag="RESULT" title="결과">

실제 행사 진행에 쓰인 실용적인 도구였다. 화면마다 역할을 나누고 그 상태를
실시간으로 동기화하는 구조를 설계해본 경험은, 비슷한 시기에 만든
[실시간 프롬프터](/projects/live-prompt/)와 관심사가 이어지는 지점이기도
하다 — "여러 화면의 상태를 하나로 맞추는 일"에 은근히 자주 끌리는 것
같다.

</Stage>
