<Stage tag="MOTIVE" title="왜 만들었나">

밴드 공연 중에 보컬은 가사를, 기타는 코드를 봐야 하는데 그걸 실시간으로
동기화해서 보여줄 수 있으면 편하겠다는 생각을 했다. 문제는 이 생각을 할
당시 나는 다룰 줄 아는 악기도, 밴드 경험도 전혀 없었다는 것 — 순전히
"언젠가 밴드를 한다면 필요하지 않을까"라는 상상만으로 시작한 프로젝트다.

<Callout label="TMI">
심지어 고3, 대입을 앞두고 잠깐 딴짓하며 만들었다. 지금 생각해도 왜 그
타이밍이었는지는 잘 모르겠다.
</Callout>

</Stage>

<Stage tag="BUILD" title="어떻게 만들었나">

Flask와 DB 마이그레이션 기반으로 백엔드를 구성했다. 곡과 유저를 등록해
셋리스트를 짜면, 각 유저가 보는 화면에 실시간으로 가사나 악보가 동기화되어
표시되도록 만들었다. 공연 중 여러 명이 각자 다른 화면을 봐야 하는 상황을
가정하고 설계한 구조다.

</Stage>

<Stage tag="RESULT" title="결과">

아직 실제 밴드에서 써본 적은 없다. 하지만 여러 클라이언트의 상태를
일관되게 유지해야 하는 실시간 동기화라는, 기술적으로는 꽤 흥미로운 문제를
다뤄본 프로젝트였다. 당장 필요는 없지만 "있으면 멋질 것 같아서" 만든
프로젝트라는 동기 자체가, 지금 와서 보면 제일 솔직한 부분인 것 같다.

</Stage>
